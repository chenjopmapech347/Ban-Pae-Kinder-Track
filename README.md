# KinderTrack

ระบบบันทึกพัฒนาการเด็กปฐมวัย (React + Vite) สำหรับครู ผู้ดูแลระบบ และผู้ปกครอง

## เริ่มใช้งาน

```bash
cd kinder-track
npm install
npm run dev
```

เปิดเบราว์เซอร์ที่ `http://localhost:5173`

## รหัสเข้าสู่ระบบ (ค่าเริ่มต้น)

| บทบาท | รหัส |
|--------|------|
| ครู | `teacher123` |
| ผู้ดูแลระบบ | `admin123` |
| ผู้ปกครอง (น้องบันทิพัฒน์) | `1234` |
| ผู้ปกครอง (น้องปณิสรา) | `5678` |

เปลี่ยนรหัสครู/แอดมินได้ที่ **ตั้งค่าระบบ → รหัสผ่านเข้าระบบ** (หลังล็อกอินแอดมิน)

## ฟีเจอร์หลัก

- **localStorage** — ข้อมูลอยู่ในเครื่ือหลังรีเฟรช
- **ล็อกอิน** — ครู / แอดมิน / ผู้ปกครอง (PIN)
- **เช็คชื่อ & กิจวัตร** — อัปเดตสถิติมาเรียนอัตโนมัติ
- **ส่งออก Excel** — รายงานรายคน, รายชื่อนักเรียน, บันทึกรายวัน
- **สำรอง JSON** — ดาวน์โหลด/นำเข้าในเมนูตั้งค่า
- **ซิงค์ Supabase** (ถ้าตั้งค่า `.env`) — อัปโหลด/ดึงข้อมูลขึ้นคลาวด์
- **วันหยุด** — จัดการในแท็บ Admin
- **นำเข้า Excel 2568** — รองรับไฟล์สรุปผลจากระบบเดิม (ดูด้านล่าง)

## นำเข้า Excel จากระบบเดิม (ปี 2568)

แอดมิน → **ภาพรวม** → นำเข้า:

| ไฟล์ | เนื้อหา |
|------|---------|
| `สรุปผลการประเมินปฐมวัย_2568_fixed.xlsx` | รายชื่อนักเรียน + คะแนนตัวบ่งชี้ 3.1.1–3.3.2 (ชีต สรุปรายนักเรียน) |
| `สรุปผลมาตรฐานปฐมวัย_2568.xlsx` | สรุป QA มาตรฐาน 1–2–3 รายโรงเรียน (แท็บ QA) |

- **ผสาน** หรือ **แทนที่** รายชื่อนักเรียน (ระบบถามตอนนำเข้า)
- หัวข้อประเมินอัปเดตตามคอลัมน์ในไฟล์
- ชื่อโรงเรียนดึงจากไฟล์มาตรฐานอัตโนมัติ

## ตั้งค่า Supabase (ไม่บังคับ)

1. สร้างโปรเจกต์ที่ [supabase.com](https://supabase.com)
2. รัน SQL จากไฟล์ `supabase/schema.sql` ใน SQL Editor
3. คัดลอก `.env.example` เป็น `.env` แล้วใส่ URL และ anon key
4. รีสตาร์ท `npm run dev`
5. ล็อกอินแอดมิน → ตั้งค่า → **อัปโหลดขึ้นคลาวด์**

> นโยบาย RLS ใน schema เป็นแบบ demo (เปิดอ่าน/เขียนสาธารณะ) — ปรับก่อนใช้ production จริง
