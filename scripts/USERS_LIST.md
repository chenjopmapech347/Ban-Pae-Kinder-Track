## 🔥 วิธีรัน Firebase Seed Script

```bash
# 1. ดาวน์โหลด serviceAccount.json จาก
#    Firebase Console → Project Settings → Service accounts → Generate new private key
#    วางไว้ที่ kinder-track/serviceAccount.json

# 2. ติดตั้ง dependencies
npm install firebase-admin

# 3. รัน seed script
node scripts/seedFirebase.js
```

> ⚠️ **หมายเหตุ**: อย่า commit ไฟล์ `serviceAccount.json` ขึ้น Git  
> เพิ่ม `serviceAccount.json` ใน `.gitignore`
